# TeamSpace 🚀

**TeamSpace** is a modern, collaborative web portal designed for team communication, task management, and administrative tracking. Built with Django and designed with a responsive, modern UI, it brings team workflows into a single unified platform.

## ✨ Features

- **📊 Centralized Dashboard:** Key team performance metrics and quick activity summaries.
- **📩 Internal Mail System:** Full inbox, sent items, drafts, and archive workflows.
- **📋 Task Management:** Integrated task boards with deadline tracking and status indicators.
- **💬 Real-Time Team Chat:** Dedicated channel for instant communication among team members.
- **📅 Interactive Calendar:** Visual schedule view for task deadlines and important events.
- **🔔 Notification Center:** Instant notifications for new tasks, messages, and announcements.
- **📱 Fully Responsive Design:** Adaptive layout optimized for Desktop, Tablet, and Mobile devices.
- **🔒 Role-Based Access:** Role-based access control (Super Admin, Manager, Team Member) with Django Admin integration.

---

## 🛠️ Tech Stack

- **Backend:** Django 5.x, Python 3.10+
- **Frontend:** HTML5, CSS3 (CSS Grid & Flexbox), Vanilla JavaScript
- **Database:** SQLite (Development) / PostgreSQL (Production)
- **Web Server & Proxy:** Nginx, Gunicorn
- **SSL Security:** Let's Encrypt (Certbot)
- **Deployment:** Ubuntu 22.04 LTS (DigitalOcean)
